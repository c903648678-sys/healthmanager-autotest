# 接入与验收

工作台已接入 API/UI 执行并验证本地合成流程。真实产品的网址、身份、API 契约、页面结构和业务规则待提供。

| 候选流程（待产品确认） | 验收内容 | 状态 |
| --- | --- | --- |
| 登录与租户隔离 | 正常登录、过期会话、跨角色与跨租户拒绝 | 待接入 |
| 健康档案 | 新建、检索、修改、权限、删除清理 | 待接入 |
| 健康指标 | 单位、边界值、时间、重复录入 | 待接入 |
| 健康评估 | 根据已确认规则核对输入与结果 | 待接入 |
| 干预与随访 | 计划创建、执行、状态流转、数据一致性 | 待接入 |

后续需提供：测试环境 URL、接口文档、登录机制、角色矩阵、关键页面与主流程、业务规则、可使用的合成数据及清理机制。

真正端到端验收至少覆盖一条经确认的流程：准备合成测试数据 → UI 操作 → API 或持久化可见结果核验 → 清理 → 记录证据。不得以本地浏览器自检或首页冒烟替代。每条用例应记录需求编号、前置条件、操作、预期、清理与自动化状态；未经确认的流程保持待接入。
