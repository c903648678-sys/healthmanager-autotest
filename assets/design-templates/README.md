当前集合为“华为云测试设计模板（用户提供）”，未另行核验官方发布版本。9 份 XMind 共解析 1819 个主题。

## 归档结构

`huawei-cloud/v1/manifest.json` 记录模板 ID、适用范围、原文件名、版本、主题数量，以及原件和提纲的 SHA-256。

每份模板存于独立 ID 目录：原始 `.xmind` 字节不变；`outline.md` 提取全部画布的主题树、普通备注供预览和模型使用。XMind 的样式、图像和关系线仍保留在原件中，文本提纲不复刻其视觉布局。

| ID | 模板 | 使用建议 |
| --- | --- | --- |
| e2e | E2E 场景 | 默认基础方法：因子、业务场景、异常、长期运行、历史问题与回归 |
| api | 接口 | 参数、返回值、业务处理、一致性、异常及专项 |
| integration | 集成 | 跨特性交互、数据、配置和上线准入 |
| performance | 性能 | 环境、梯度/浪涌/风暴/震荡/混合负载与指标 |
| reliability | 可靠性 | 故障模式、业务对象、检测、降级、恢复 |
| security | 安全隐私 | 安全、隐私生命周期、白盒与 Fuzz |
| app | App | 兼容性、界面、稳定性和资源消耗 |
| vehicle-cloud | 车联网云服务 | 行业相关需求才选用 |
| vehicle-device | 车载设备 | 行业相关需求才选用 |

## 使用与更新

工作台「测试资产 → 设计模板」支持预览提纲、查看归档信息、下载原始 XMind。「测试方案 → 测试设计模板」可选择 1～3 份，默认 E2E。原始外部目录不再是运行依赖，复制仓库到其他电脑时需同时保留本目录。

模板作为方法资产单独管理，不混入产品知识事实，不计入 UI/API 用例统计。示例订单、工单、行业业务及历史阈值不是当前需求的验收标准。

后续内容更新应建立新归档版本并更新加载配置，不能覆盖已发布原件。作业 input.json 保存所用模板全文与校验值，后续用例继承已确认方案的快照。数据备份包含作业中的模板快照；原始模板随仓库单独备份。

首次归档工具：`python -m workbench.import_templates <来源目录>`。当前导入器面向本批次的 9 个固定文件名；不是任意格式的通用上传入口。
